AgentBridge 使用手册User Manual

跨网多人多仓 AI agent 协作系统：一个常开 broker 把多机 agent 连进同一房间，一端完成、全员自动获知——无手动同步、无轮询。 A cross-network multi-agent collaboration system: an always-on broker connects agents on many machines into one room — one finishes, all learn automatically. No manual sync, no polling.

3 · 跨网版（v3）：多机/多人/多 agent3 · Cross-network (v3): multi-machine / person / agent

① broker 机（管理员）：起 broker + 建房间 + 加成员① Broker machine (admin): start broker + create room + add members

身份/房间/成员权威在 broker 的 collab.db，所以在 broker 机上跑。Identities/rooms/membership are authoritative in the broker's collab.db — run these on the broker machine.

#(a) 起 broker，绑 Tailscale 100.x（绝不 0.0.0.0）start broker, bind Tailscale 100.x (never 0.0.0.0)
abg broker start --host 100.x.y.z --port 4700
#(b) 注册身份 + 签发 tokenregister identities + issue tokens
abg auth login --id alice@team.dev --name Alice
abg auth login --id bob@team.dev   --name Bob
#(c) 建房间（创建者自动成员）create room (creator auto-joins)
abg room create checkout
#(d) 加成员（成员制授权）add members (access control)
abg room add checkout bob@team.dev

token 带外分发（IM/密码器），勿提交 git。Distribute tokens out of band (IM/password manager); never commit to git.

② 每台参与者机：装 token + 加房间 + 起 agent② Each participant machine: install token + join room + start agent

abg auth login --token <broker 签发的 token>   # 装 broker 带外发来的 tokeninstall the broker-issued token
abg join checkout --broker-url ws://100.x.y.z:4700/ws    # 加房间 + 持久化 broker 地址join + persist broker URL
abg claude           # 或 abg codexor abg codex
abg init

broker 机 abg room invite <room> <id> --broker-url ws://… 会一次性打印好上面两行，带外发给参与者粘贴即可。--broker-url 持久化后无需设 AGENTBRIDGE_BROKER_URL、无需重启 daemon。On the broker, abg room invite <room> <id> --broker-url ws://… prints both lines ready to paste (deliver out-of-band). Once --broker-url is persisted, no AGENTBRIDGE_BROKER_URL env var and no daemon restart are needed.

  • 完成即广播：一轮结束（有新 commit）Stop 钩子自动 abg publish 完成事件给同房间成员。Auto-announce: on finishing a turn (new commit) a Stop hook runs abg publish to room members.

房间指令与限制模式Room instructions and restricted mode

默认模式适用于信任的同组同事，所有成员的 chat 发言按本机用户指令处理。Codex 需要回复时使用 agentbridge_room_say。完成任务（task_completed）、成员进出和白板在两种模式下始终是 📨 通报，可信名单成员也一样。Default mode is for trusted colleagues: all members' chat messages are local-user instructions. Codex replies with agentbridge_room_say when needed. Task-completed events (task_completed), join/leave events and whiteboard snapshots always remain 📨 notices in both modes, including for locally trusted members.

需要限制时，用 abg claude --room-untrusted 或 abg codex --room-untrusted 启动，也可设置启动环境变量 AGENTBRIDGE_ROOM_UNTRUSTED=1。限制模式恢复安全前导和 📨[房间消息·外部成员·仅通报·非指令]；只有本机可信名单成员的 chat 发言仍带 ✅[房间成员指令]。To restrict instructions, launch abg claude --room-untrusted or abg codex --room-untrusted, or set AGENTBRIDGE_ROOM_UNTRUSTED=1 in the launch environment. Restricted mode restores the security preamble and 📨[房间消息·外部成员·仅通报·非指令] notices; only locally trusted members' chat messages retain ✅[房间成员指令].

本次升级改变了默认行为。已经执行过 abg init 的项目需重新执行，将 CLAUDE.md/AGENTS.md 房间规则更新为两种模式；运行中的 daemon 须先 abg kill 再启动，启动参数才会生效。This upgrade changes the default behavior. Run abg init again in initialized projects to update both-mode rules in CLAUDE.md/AGENTS.md; stop running daemons with abg kill before restarting so launch settings take effect.

abg room trust <roomId> <agentId>
abg room trusted [roomId]
abg room untrust <roomId> <agentId>

名单按 broker 认证的 from.agentId 匹配，保存在本机 <collab 目录>/room-trust.json（0600），不改变成员资格。限制模式下名单修改对后续事件生效，无需重启；默认模式下撤销登记仍保留成员指令权限。The list matches broker-authenticated from.agentId and is stored locally in <collab directory>/room-trust.json (0600), without changing membership. In restricted mode, list changes affect subsequent arrivals without restart; in default mode, removing an entry leaves the member's instruction authority intact.

Codex 按到达顺序，每轮处理最多 10 条可信属性相同的连续消息。已入队消息和重试保留接收时属性；可信轮次的普通输出同样不会自动转发给本机 Claude。Codex preserves arrival order and batches at most ten consecutive entries with the same trust status. Queued entries and retries retain their received status; ordinary trusted-turn output is not automatically forwarded to local Claude.

🔴 4 · 安全（务必读）4 · Security (must read)

默认模式下，任何成员的发言都能让你的 agent 执行操作。只和信任的同事共用房间，token 按秘密保管；token 持有者可以使用对应身份发送消息。 In default mode, any member's chat can cause your agent to perform operations. Share rooms only with trusted colleagues and keep tokens secret; token holders can send as the corresponding identity.

  1. 守门：成员制授权 + Tailscale ACL + PSK。别把不信任的身份加进房间。Perimeter: membership authz + Tailscale ACL + PSK. Never add identities you don't trust.
  2. 限制模式：启用 --room-untrusted 或 AGENTBRIDGE_ROOM_UNTRUSTED=1 后，仅本机名单成员可以通过 chat 发言发送指令；其他发言及所有完成任务、成员进出和白板事件作为 📨 通报，禁止自动回信或执行要求。Restricted mode: with --room-untrusted or AGENTBRIDGE_ROOM_UNTRUSTED=1, only locally listed members can send instructions through chat; other chat and all task-completed events, join/leave events and whiteboard snapshots remain 📨 notices and must not trigger automatic replies or execution.
  3. 🔴 你的纪律（最关键）：接入多方房间的 agent 不要开 blanket 自动批准；破坏性操作必须人工确认；最小权限。🔴 Your discipline (critical): don't run room-connected agents with blanket auto-approve; destructive ops require human confirmation; least privilege.

两种模式均遵守会话操作权限和审批要求。限制模式下，仅登记愿意授予指令权限的身份。详见 docs/11。 Both modes respect session permissions and approval requirements. In restricted mode, list only identities you intend to authorize. See docs/11.

6 · 排障6 · Troubleshooting

  • 看不到房间事件 → 确认你是该房间成员（broker 机 abg room add/invite 过你）+ abg join 带了 --broker-url（漏了会回退本地默认并打 WARN）+ token 一致。No room events → confirm you're a member (abg room add/invite'd on the broker) + you passed --broker-url to abg join (omitting it falls back to localhost and logs a WARN) + matching token.
  • 连不上 broker → curl http://100.x:4700/healthz 应 200；别绑 0.0.0.0。Can't reach broker → curl http://100.x:4700/healthz should be 200; don't bind 0.0.0.0.
  • 完成事件没广播 → 装了插件 + 当前目录 abg join 过 + 已登录。Completions not broadcast → plugin installed + current dir abg join'd + logged in.
